### 요약

# Today

## 학습 내용

- Hugging Face Transformers를 이용해 사전학습된 모델(BERT 등)을 불러와 활용하는 방법을 학습하였다.
- Tokenizer는 문장을 토큰과 ID로 변환하며, BERT는 **Subword Tokenization**을 사용한다.
- BERT는 **Encoder 기반 모델**로 문장의 문맥을 이해하고 각 토큰의 **Contextual Representation**을 생성한다.
- Hidden State는 각 토큰의 의미를 담은 벡터이며 문맥에 따라 같은 단어도 다른 표현을 가진다.
- **[CLS]**는 문장 전체를 대표하는 토큰이다.
- **[SEP]**는 문장 구분 토큰이다.
- **[MASK]**는 Masked Language Model에서 예측 대상이 되는 토큰이다.
- Masked Language Model(MLM)을 통해 `[MASK]` 위치의 단어를 예측하는 원리를 실습하였다.
- BERT Config를 확인하며 `hidden_size`, `intermediate_size`, `num_hidden_layers`, `num_attention_heads` 등 모델 구조를 이해하였다.
- Transformer Block의 파라미터 수를 계산하며 모델 구조와 크기를 분석하였다.
- BertViz를 사용하여 Self-Attention을 시각화하고 Layer와 Head별 Attention 패턴을 관찰하였다.
- 중의어(예: **말**)를 포함한 두 문장을 비교하여 문맥에 따라 Attention이 향하는 토큰이 달라질 수 있음을 확인하였다.
